Firebase Setup Required

To save data across all devices, this app needs a free Firebase project.
It takes 2 minutes — follow the steps below.

1 Go to console.firebase.google.com → Create project (any name)
2 Click Build → Realtime Database → Create database → choose "Test mode" → Done
3 Click the ⚙️ gear → Project Settings → scroll to "Your apps" → click </> Web → Register app → copy the firebaseConfig
4 Paste your config JSON below and click Save
